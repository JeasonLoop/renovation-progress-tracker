# 通用操作弹窗设计

## 目标

用站内一致、可访问的操作弹窗替代浏览器 `alert`、`confirm` 和后续类似阻塞提示，首先覆盖预算项删除。

## 方案

- 在根布局挂载 `OperationDialogProvider`，业务组件通过 `useOperationDialog` 调用。
- `confirm` 返回 `Promise<boolean>`，保留接近原生确认框的顺序控制能力。
- `notify` 返回 `Promise<void>`，用于成功、错误或普通提示。
- 支持 `neutral`、`danger`、`success` 三种语义色，不扩展不必要的弹窗类型。

## 交互

- 危险确认默认聚焦取消按钮，避免用户按回车误删。
- Esc 和点击遮罩等价于取消；弹窗打开时锁定页面滚动。
- 桌面端居中显示，移动端贴近底部安全区并让操作按钮等宽排列。
- 使用 `alertdialog`、标题和描述关联，按钮保留明确的可访问名称。

## 视觉

延续现有 6 至 8 像素圆角、冷灰表面和单一陶土色强调体系。危险操作使用已有危险色，仅图标区和主操作按钮着色，不使用渐变、玻璃卡片或大面积警示色。
