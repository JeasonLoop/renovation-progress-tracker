# 项目图片大图预览设计

## 目标

让用户在不离开当前装修记录上下文的情况下查看上传图片细节，并覆盖附件编辑、验收证据、施工日志和材料候选中的项目图片。

## 交互

- 点击缩略图打开全屏灯箱，图片按原比例完整显示。
- 多张图片可使用左右按钮、键盘方向键或移动端横向滑动切换。
- 点击关闭按钮、遮罩或按 Esc 退出预览。
- 顶部显示图片名称和当前位置，删除操作仍是缩略图上的独立按钮。

## 实现

- `ImageLightbox` 负责全屏展示、导航、键盘事件、触摸手势和页面滚动锁定。
- `PreviewableImageList` 为只读图片列表提供统一的缩略图入口。
- `ImageAttachments` 自行管理当前预览索引，使编辑与预览共存且不会误触删除。
- 灯箱通过 portal 挂载到 `document.body`，避免被页面布局的层叠上下文裁切。

## 响应式与无障碍

- 桌面端图片区域保留四周操作空间；移动端按安全区调整顶栏和底部控件。
- 使用 `dialog` 语义、可读按钮标签，并在打开时把焦点移到关闭按钮。
- 图片使用 `object-fit: contain`，不裁切装修现场细节。
